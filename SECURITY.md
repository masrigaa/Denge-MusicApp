# Security Policy

## Supported Versions

We actively support and provide security updates for the following versions of Déngé:

| Version | Supported          |
| ------- | ------------------ |
| 1.5.x   | :white_check_mark: |
| 1.4.x   | :x:                |
| < 1.4.0 | :x:                |

We strongly encourage all users to update to the latest available release to benefit from security fixes, stability enhancements, and library updates.

## Reporting a Vulnerability

The Déngé development team takes security and user privacy seriously. If you discover a security vulnerability, we appreciate your help in disclosing it to us responsibly.

### How to Report

1. **Private Vulnerability Reporting**:
   Please report any suspected security vulnerabilities privately using GitHub's **Report a vulnerability** feature under the **Security** tab of this repository:
   [https://github.com/masrigaa/Denge-MusicApp/security/advisories/new](https://github.com/masrigaa/Denge-MusicApp/security/advisories/new)

2. **Alternative Contact**:
   If private reporting is unavailable, you may reach out directly to the maintainer via GitHub profile ([@masrigaa](https://github.com/masrigaa)).

### What to Include

To help us triage and resolve the issue quickly, please include:
- A clear description of the vulnerability and its potential impact.
- Steps to reproduce the issue (including sample code, payloads, or screenshots if applicable).
- Device and Android OS version tested.
- Any suggested mitigations or patches, if available.

### What to Expect

- **Acknowledgment**: We will review and acknowledge your report within 48 hours.
- **Investigation**: We will validate the issue and coordinate a fix in a private branch.
- **Disclosure**: Once resolved, a patch release will be published and credit will be given to the reporter (unless you prefer to remain anonymous).

Please do **not** disclose the vulnerability publicly (e.g., via public GitHub Issues or social media) before a fix has been released.
